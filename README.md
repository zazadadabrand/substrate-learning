# Substrate Learning

Reverse engineering specific outcomes into deterministic curricula that compound over time. Built by Bernard Studia.

One substrate stack per discipline. Every atom is taught, timed, and tested inside the system: a from zero lesson, a reference sheet, and a drill with a pass condition. The active track is Creative Director, sculpted from a cohort of nineteen reference practitioners.

## Stack
Single file static app: index.html. No build step, no dependencies beyond Google Fonts. Progress persists via the host storage API where available and degrades gracefully where not.

## Protocol
1. Every version is committed to this repository. Version verifiability is a mandate, not a habit.
2. The repository is connected to Vercel. Every push to main deploys automatically. Committed equals live.
3. Versions increment through Bloom passes: research on the cohort, new materials, gap log input, and pace recalibration.
4. Every material holds one standard: written so simply a kid could learn from it.

## Deploy
1. Create a GitHub repository and push this folder.
2. In Vercel: Add New Project, import the repository, framework preset Other, no build command, output directory root. Deploy.
3. Every future version arrives as a new commit and goes live on push.
